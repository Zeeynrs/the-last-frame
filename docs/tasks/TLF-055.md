### C. `dead_relay_c` sorting: `YSort_Actors` (z 10), as in rows 225-226

Decision: **freestanding, `YSort_Actors` (`z_index = 10`)**. The prose sentence in `ASSET_METADATA.md` (§"Bible Named Layer Reconciliation (R3)", "breakers/relays" under `Wall_Fixtures`) is the one to correct.

Reasons:
1. The spec puts lever C at tile `(6,2)` `(384,128)`: two tiles in from the north-east wall (the wall line runs along tile `y = 0`, `(320,64)→(544,176)`), not on it. The wall-mounted Step 1 objects all sit on a wall tile (`y = 1` for the SO-01 selectors and the PZ-006 dials, `x = 0` for `breaker_c` and `doc_bus_chart`).
2. Tile `(6,1)` behind it is walkable floor (the room's only static collider is the perimeter outline). A `Wall_Fixtures` sprite (z 7) always draws under the player, so a player standing behind the relay would be drawn in front of it. Only the Y-sorted actor layer gets that overlap right.
3. It is the third relay of the same bank as levers A/B in this room, which are also freestanding and whose presenters already draw at absolute `z_index = 10` (`upper_vestibule.tscn`).
4. The spec gives it no body collider (`ROOM_GRAPH.md` §10.1 R7 lists only the statue footprint), so it stays an `Area2D` with no new fingerprint entry, like levers A/B.

Sprite: idle by default; `shake` for a short moment when `interaction_failed` reports `dead_relay` for this target (presenter only, no logic).
