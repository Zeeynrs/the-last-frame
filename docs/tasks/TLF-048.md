# Task: TLF-048 — Playtest telemetry: measure time per room and puzzle (local)

**Owner:** Opus implementation agent (`wt-opus-core`, branch `agent/opus-core`) · **Status:** READY · **Priority:** P1 (yardstick for ADR-020) · **Dependencies:** `main` at `36f54de`+

## Why (ADR-020)
"Too short" needs a number. Right now we only have an estimate (38 min) and the times of the scripted perfect runs. Telemetry gives real first-time times per room/puzzle for every following playtest.

## Requirements
- `PlaytestLog` (session-scoped or under `scripts/session/`; your call, justify it). It records, on SimClock ticks (and wall time for comparison):
  - room enter/exit (time per room, incl. repeat visits)
  - per puzzle: first room entry → SOLVED (ticks), number of resets/`echo_reset`, hint requests per level, failed interactions by reason
  - total time, time to `chapter_complete`
- Pauses (document/journal/dialogue pause, game pause) are recorded **separately**, not mixed into the puzzle time.
- Output:
  - On `chapter_complete`: a compact summary on the complete screen (total time + per-puzzle minutes; text via `tr`, ASCII; new keys appended to `localization/ui_feedback.csv` + `.translation`).
  - **And** a JSON file under `user://playtest/ch01_<timestamp>.json`. That's a new folder; it never touches `saves/` or `settings.cfg`. Headless: `user://headless/playtest/` (TLF-036 rule).
- Survives save/load: the log state lives in the save (migration if the save schema needs it: ADR-011/SaveStore rules, version bump, migration test).
- Can be switched off: `Settings`? No: a `ProjectSettings` flag `tlf/playtest_log` (default true in debug builds, false in export), so `settings.gd` doesn't need to change.

## Allowed files
`scripts/session/**` or a new `scripts/telemetry/**`, `scripts/save/**` (schema + migration only), `scripts/chapters/ch01/chapter01.gd` (complete-screen summary + hooks only; a minimal change, since it's Flash's file), `localization/ui_feedback.csv` (append) + `.translation`, `project.godot` (the `tlf/playtest_log` key only), `tests/telemetry/**`, `tests/save/**`.

## Acceptance criteria
- [ ] `tools/validate.ps1` passes on a fresh clone; genuine raw output.
- [ ] Tests:
  - times per room/puzzle against a scripted real-input run (rooms 1–4 from TLF-030); the ticks match the SimClock
  - pauses not counted
  - save/load keeps the log
  - migration of an old save
  - JSON lands under the headless path in tests, never under `user://saves`
  - flag off → no file, no summary
- [ ] Windowed check in a renamed-config copy: complete screen with summary; JSON file content in the handoff. The real save folder only listed, never written.

## Stop conditions
Stop and report if hooks are needed in Flash's UI scripts beyond `chapter01.gd`, or if the save schema change collides with existing saves in a way a migration can't absorb.
