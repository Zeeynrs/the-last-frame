# Task: TLF-058 — Operator sighting on the Arrival Platform (Story Bible Ch1 event 7)

**Owner:** Flash · worktree `tlf-implementation-qa`, new branch from `main` · **Status:** BLOCKED (TLF-055 merged; placeholder art allowed until TLF-062) · **Priority:** P0 · **Decision:** ADR-022 D3, `docs/OPERATOR_MYSTERY_GUIDELINES.md` (binding)

## Goal
After Elias picks up the pocket watch, a silent figure stands at the far end of the Arrival Platform, back to the camera, and lifts and checks a pocket watch. When Elias walks closer, the figure is gone. It happens once per save.

## Requirements
1. **Placement:** at the far end of the platform, inside the room, visible from the pickup spot. It doesn't block any path and has no collision. Propose the exact tile in the handoff; the Lead approves the composition, because Ending 3 reuses it exactly.
2. **Trigger:** the watch-pickup flag → the figure appears. Elias enters a `TriggerZone` about 4 tiles from it → it fades out over 0.5 s (static cut with `reduced_effects`) → flag `ch01.flag.operator_sighting_seen` + journal `JRN_CH1_FIGURE` (observation; the key exists).
3. **No input lock and no dialogue.** Add a hook for a quiet audio sting (TLF-064 fills it).
4. **Save/load:** after the flag is set, the figure never appears again. Before it is set, loading at the arrival checkpoint shows the figure again.
5. **Art:** a placeholder silhouette (dark palette shape, hood, no face) with a texture export ready for TLF-062. The "check watch" gesture is a 3-4 frame placeholder.

## Allowed files
`scenes/chapters/ch01/rooms/arrival_platform.tscn` (new nodes only; existing collision unchanged, fingerprint in the handoff), a new `scripts/chapters/ch01/operator_sighting.gd`, `tests/chapters/ch01/**` (wiring + save/load tests).
