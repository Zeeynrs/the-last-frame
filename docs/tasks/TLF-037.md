# Task: TLF-037 — F5 plays the game: Boot → title screen → Chapter 1 (New Game / Continue / Quit)

**Owner:** Opus implementation agent (`wt-opus-core`, branch `agent/opus-core`) · **Status:** READY (after TLF-036) · **Priority:** P1 (the user can't start the game) · **Dependencies:** TLF-036 (Continue must not read real saves during tests)
**Decision:** ADR-011 amendment 2026-10-31 (TLF-037): `SceneRouter` becomes the 4th autoload.

## Why (ISSUE-027)
`run/main_scene` = `res://scenes/boot/Boot.tscn`. `scripts/core/boot.gd` is just `pass`, and the label is a placeholder that also contains non-ASCII (`—`, which the pixel font can't render). F5 shows a black screen. The user currently has to open `Chapter01.tscn` and press F6, which we don't want for a vertical slice or a playtest.

## Requirements
1. **`SceneRouter` autoload** (`scripts/core/scene_router.gd`, registered in `project.godot` as `SceneRouter`):
   - `start_chapter(scene_path: String, restore_slot: int = -1)`: loads the chapter scene with `change_scene_to_file` or `to_packed`; remembers `restore_slot` as pending.
   - `consume_pending_restore() -> int`: returns the slot and clears it (−1 if none).
   - `return_to_title()`.
   - No `class_name` equal to the autoload name (ADR-011 note TLF-027).
2. **Boot** (`scripts/core/boot.gd`, `scenes/boot/Boot.tscn`): loads translations / Settings, then routes deferred to the title screen. Remove the placeholder label.
3. **Title screen** (`scenes/ui/title_screen.tscn`, `scripts/ui/title_screen.gd`), 640×360, TLF Pixel Mono, ASCII:
   - Title `UI_TITLE_GAME` ("THE LAST FRAME")
   - Menu `UI_TITLE_NEW_GAME`, `UI_TITLE_CONTINUE` (only active when `SaveService.has_slot(0)`), `UI_TITLE_QUIT`
   - Navigable with keyboard (`move_up/down` + `confirm`/`interact`) and controller; mouse optional
   - New Game when a save exists: one confirmation line `UI_TITLE_OVERWRITE_CONFIRM` (the save is only overwritten at the first checkpoint, not right away)
   - Add the keys to `localization/ui_feedback.csv` **(append only; don't change existing lines)** and regenerate the committed `.translation` (ADR-013).
4. **Chapter01 restore hook** (`scripts/chapters/ch01/chapter01.gd`, a minimal change in `_ready` only): if `SceneRouter.consume_pending_restore() >= 0` → `room_router.restore_from_save(SaveService.read_slot(slot))` instead of `enter_room(arrival_platform)`. If the restore fails (`ok == false`): start fresh and show a HUD feedback line. Don't change anything else in that file (it's Flash's; TLF-034 doesn't touch it).
5. After `chapter_complete`: `confirm` on the complete screen → `SceneRouter.return_to_title()`. If that needs more than a few lines in `chapter01.gd`, list it as a follow-up in the handoff instead.

## Allowed files
`scripts/core/**`, `scenes/boot/**`, `scenes/ui/title_screen.tscn`, `scripts/ui/title_screen.gd`, `project.godot` (autoload `SceneRouter` only; `run/main_scene` stays Boot), `localization/ui_feedback.csv` (append) + `localization/ui_feedback.en.translation`, `scripts/chapters/ch01/chapter01.gd` (requirements 4 and 5 only), `tests/core/**`, `tests/ui/test_title_screen.gd`, `tests/test_project_settings.gd` (autoload list).
