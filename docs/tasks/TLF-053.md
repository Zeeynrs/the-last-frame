# Task: TLF-053 — Art: ability wheel and ability icons

**Owner:** Design-art agent: Claude Code (Sonnet 5.5), worktree `tlf-design-art`, branch `adityadaffa522/tlf-art-batch2` (`git pull origin main` first). **Do it after TLF-047 phase 2, or in between if phase 2 is waiting on feedback.**
**Status:** READY · **Priority:** P1 (user request) · **Decision:** ADR-021 (read first)

## Goal
Art for the ability wheel from the user's sketch: a round pocket-watch face in the centre with a pointer, and 6 segments around it (Trace, Rewind, Freeze, Echo, Fast-Forward, unknown "?"), each in the states unlocked / selected / locked.

## Requirements
- **Size:** the whole wheel fits the 640×360 view with a 12 px safe margin, centred. Suggestion: ~160×160 px; propose a number, justified by readability at ×3.
- **Pieces as separate PNGs** (so Flash can assemble them):
  - watch face (centre)
  - pointer (rotatable: either 8 pre-rendered directions **or** one sprite that stays pixel-clean at 45° steps; justify it, since pixel art doesn't rotate cleanly at arbitrary angles)
  - segment backgrounds per position × {normal, selected, locked}
  - ability icons 16×16 for Trace, Rewind, Freeze, Echo, Fast-Forward
  - "?" icon
  - lock glyph
- **The icons double as HUD slot icons** (ART_BIBLE §8.1: 16×16 ability slots).
- **No-colour readability:** each icon has its own shape (ART_BIBLE VFX language); locked = lock shape + greyed. Include a greyscale proof PNG.
- Palette TLF-CH01-32 only, binary alpha, generators in `tools/art/gen/` (`verify_regen.py` ALL REPRODUCIBLE), metadata + `.pxo` with Pixelorama verification as in TLF-039.
- A mockup PNG of the full wheel (640×360) in 3 states: only Trace unlocked; all four; Rewind selected.

## Allowed files
As TLF-042, plus PNG exports in `assets/ui/` (new folder `assets/ui/ability_wheel/`).

## Acceptance criteria (raw output only)
- [ ] Pixelorama `--size` + `--export` OK, re-export pixel-identical (temp copy).
- [ ] `check_assets.py` ALL PASS (extended to `assets/ui/ability_wheel/` if needed).
