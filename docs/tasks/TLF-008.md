## Requirements
- **TemporalComponent** (`Node`, child of the temporal object), exactly per ADR-007 amendment 2:
  - members: `capabilities` flags, `schema_version`, `state_fields`, `initial_history: Array[Dictionary]`, `is_frozen`
  - the parent implements `capture_state() -> Dictionary` and `apply_state(d)`
  - history: snapshot list plus `cursor`, capacity 32
  - `commit_history()` is called by the parent on discrete transitions only
  - `rewind() -> StringName` (`&""` / `&"no_history"` / `&"frozen"` / `&"unsupported"`), `toggle_freeze() -> StringName`
  - `get_history_cursor()` / `set_history_cursor()` for future saves
  - validates that every snapshot contains exactly `state_fields` (`push_error` otherwise)
- **Interactable delegation:** `can_interact` / `interact` for `trace`/`rewind`/`freeze`/`fast_forward` route to the child `TemporalComponent`. With no component, or a missing capability → `&"unsupported"`. A frozen object rejects `use` and `rewind` with `&"frozen"`. A parent may override with its own cross-object rules (e.g. a test shutter that is blocked by a frozen test gear).
- **Trace:** `trace` succeeds on objects that declare a trace locus (a simple `@export var traceable: bool`) and emits a `traced(object_id)` signal. The visual is a placeholder.
- **Pocket watch** (Player child):
  - abilities unlocked via an exported list; `ability_next`/`ability_prev` cycle in the ADR-015 order (skip Echo for now if it's in the list, or show it as "coming in TLF-016")
  - `watch` activates the selected ability on the current watch target through `InteractionService.request(&"player", target_id, <ability_id>)`
  - targeting per ADR-015: 96 px radius, nearest candidate that supports the selected ability, else nearest overall, ties by smallest `object_id`
  - highlight the current watch target (placeholder outline/label showing the ability name)
  - expose `last_result: InteractionResult` and a `watch_used(ability, target_id, result)` signal so the future HUD can show `reason` feedback
- **TemporalTestRoom** (greybox, reuses the GameSession and Player scenes), containing:
  - `ch01.test.gate` (REWIND, `initial_history` = open, starts collapsed)
  - `ch01.test.pillar` (no component)
  - `ch01.test.shutter` (REWIND, `initial_history` raised with `hold_ticks 180`, counts down per tick unless `ch01.test.gear` is frozen, commits only on raised↔closed)
  - `ch01.test.gear` (FREEZE)
  - layout: the shutter and gear within 96 px of one standing spot, to prove capability-preferring targeting
