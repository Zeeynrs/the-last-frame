# Task: TLF-052 — Ability wheel (hold Z / LT, radial selection, locked slots)

**Owner:** Agent 2 — Flash · worktree `tlf-implementation-qa` (restart the session if it has exited) · **Status:** READY (after TLF-050 is merged; art from TLF-053, a placeholder is allowed) · **Priority:** P1 (user request; part of Step 1) · **Decision:** ADR-021 (read first, binding)

## Goal
As in the user's sketch: hold `Z` (controller: LT) → a wheel with 6 segments appears around the pocket-watch face. Aim, release, and the ability is selected. Abilities that aren't unlocked yet are visibly locked.

## Requirements (details in ADR-021)
1. **Input:**
   - new action `ability_wheel` in `project.godot`: keyboard Z (physical), joypad axis 4 positive (LT), device −1
   - binding-conflict tests and `tests/test_project_settings.gd` updated
   - remappable via Settings like the other actions
2. **Wheel UI** (`scenes/ui/ability_wheel.tscn` + `scripts/ui/ability_wheel.gd`, a CanvasLayer above the HUD):
   - 6 fixed segments in ADR-015 order (Trace, Rewind, Freeze, Echo, Fast-Forward, unknown "?")
   - centre: the watch face with a pointer at the current direction
   - **Aim:** WASD/arrows (8 directions), mouse angle from the centre, left or right stick; dead zone = no change
   - **Hold mode** (default): release = select. **Toggle mode** (setting `wheel_toggle_mode`): Z/LT opens, `confirm` selects, `cancel` closes without change.
   - **Locked:** grey + lock glyph, hover text `UI_WHEEL_LOCKED`, release → no change + `ability_locked` feedback (TLF-050)
   - **Unlocked:** icon + name (`ABILITY_*` keys), current selection highlighted, newly unlocked ability pulses once (static with `reduced_effects`)
   - "?" is always locked in Ch1, with no name
3. **While open:**
   - `SimClock` paused
   - player blocked via `Player.set_input_blocked` (TLF-034 API; the swallow-on-unblock rule keeps the release from triggering a watch action)
   - the dialogue/document viewer has priority (no wheel while a modal is open)
4. **Reads only** from `AbilityUnlocks`/`PocketWatch` (TLF-050); selection via `PocketWatch.set_selected_ability`. No new unlock logic in the UI.
5. **Theme:** TLF-040 sizes (8/16/24), panel styles, and pixel-art rules (integer positions, no AA). Art comes from TLF-053; until then, a palette-based placeholder (Polygon2D segments) is fine, with the texture slots ready as exports.
6. **Text** in `localization/ui_feedback.csv` (append): `UI_WHEEL_LOCKED`, `UI_WHEEL_UNKNOWN`, and a prompt hint (e.g. "[Z] Abilities") for the HUD, via InputPrompts.

## Allowed files
`project.godot` (the `ability_wheel` action + setting default only), `scenes/ui/ability_wheel.tscn`, `scripts/ui/ability_wheel.gd`, `scenes/ui/HUD.tscn` + `scripts/ui/hud.gd` (instance + prompt hint), `scripts/settings/settings.gd` (`wheel_toggle_mode` + save/load only; keep the TLF-036 guard), `localization/ui_feedback.csv` (append) + `.translation`, `tests/ui/**`, `tests/settings/**`, `tests/test_project_settings.gd`.

## Forbidden files
`scripts/player/pocket_watch.gd` (use its API only; if something's missing, stop and report), `scripts/session/**`, `scripts/save/**`, `scripts/narrative/**` (TLF-050), Opus's real-input tests.

## Acceptance criteria
- [ ] `tools/validate.ps1` passes on a fresh clone; genuine raw output.
- [ ] Tests with **real input** (TLF-029 helpers):
  - hold Z, aim right-down (WASD), release → the right ability selected
  - aiming at a locked segment → no change + `ability_locked`
  - release in the dead zone → no change
  - toggle mode: open/confirm/cancel
  - controller: LT axis + stick → selection
  - SimClock is paused while open, then resumes
  - the release doesn't trigger a `watch` action
  - segment positions stay identical after a new unlock
  - `reduced_effects` → no pulse
- [ ] Binding-conflict tests green (Z and LT are free; check this against the project.godot actions).
- [ ] Windowed screenshots (renamed copy): wheel with only Trace unlocked, with all four, and in toggle mode, at 640×360.

## Stop conditions
Stop and report if the TLF-050 API isn't enough, if Z/LT collide with an existing binding, or if pausing the SimClock collides with an echo recording (the Lead decides whether the wheel may open during a recording).
