# Task: TLF-072 — Logical canvas 960 x 540 (ADR-023 addendum 3)

**Owner:** Opus · **Reviewer:** Lead (validation), Sol (visual of the cinematic and UI) · **Priority:** P0 · **Status:** BLOCKED until TLF-069 (pilot room) is merged at 640 x 360

## Goal
Change the internal canvas from 640 x 360 to 960 x 540 (integer x2 to 1080p) so the character looks smaller on screen. Sprites and art are not changed.

## Requirements
1. `project.godot`: `display/window/size/viewport_width = 960`, `viewport_height = 540`; keep the 1920 x 1080 window override, stretch mode viewport, aspect keep, integer scale. Update `tests/test_project_settings.gd`.
2. `RoomRouter` / `RoomCamera`: a room whose bounds are smaller than the screen is centred in the screen (camera on the bounds centre), including rooms without `metadata/room_shape` (their fallback bounds stay 640 x 360 as the old screen area, now centred). No frame shows anything outside the intended area except the dark margin. Positions stay whole pixels.
3. Beat 10 cinematic (`scripts/ui/cinematics/ch01_outro.gd`, `scenes/ui/cinematics/ch01_outro.tscn`): letterbox (black bars top and bottom so the 1280 x 360 plate keeps its pixel scale), pan 0 to -320 (plate width 1280 minus the 960 view), reduced_effects static frame at -320. Update `docs` timing table and the test.
4. UI check at 960 x 540: HUD, dialogue box, title screen, chapter-complete overlay, ability wheel, document viewer, feedback line. Text stays inside its panels, nothing is cropped or off-centre. Report the one-third smaller text honestly with screenshots; do not add a UI scale (separate decision).
5. Update every test and fixture that hard-codes 640 or 360 as the screen (about 10 files; the round-trip and camera tests included) and the ADR-003 references in comments. Art mockup tools that draw 640 x 360 proofs are left alone.
6. Evidence: windowed 960 x 540 screenshots of the title, the arrival platform, one old room (centred with margins), the pilot room, the cinematic start and end, a dialogue line, the wheel. Raw validate output, 0 failed, no SCRIPT ERROR.

## Out of scope
Rebuilding rooms larger, new art, UI scaling, elevation/stairs (ADR-024).
