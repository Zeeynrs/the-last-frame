## Objective
A Godot 4.7.2 project that imports headlessly with zero errors, has the agreed folders, input map and pixel-art display settings, and runs an automated test suite from the command line.

## Context
- `docs/ADR_LOG.md`: ADR-001 (layout), ADR-003 (display), ADR-004 (ticks), ADR-011 (autoloads), ADR-012 (test runner)
- `docs/GDD.md` §7 (controls)
- Godot console exe: `D:\Godot\Godot_v4.7.2-stable_win64_console.exe` (machine-specific: don't hard-code it in committed files; `tools/validate.ps1` takes it from the `GODOT` env var or a `-Godot` parameter)

## Allowed files
- `project.godot`
- `scenes/boot/Boot.tscn`, `scripts/core/boot.gd`
- `tests/run_tests.gd`, `tests/test_project_settings.gd`
- `tools/validate.ps1`
- `.gdignore`/`.gitkeep` placeholders under `scenes/ scripts/ tests/ data/ localization/ assets/<export folders>/`

## Forbidden files
- `docs/**` (send doc changes to Opus), `design/**`, `narrative/**`, `assets/source/**`, `icon.svg`, `.gitattributes`, `.editorconfig`, `.gitignore`
- `addons/**`: no addon installs in this task
- Autoload scripts: the services in ADR-011 are **not** part of this task

## Requirements
- [ ] `project.godot` per ADR-003/004:
  - `display/window/size/viewport_width=640`, `viewport_height=360`
  - `window_width_override=1920`, `window_height_override=1080`
  - `stretch/mode="viewport"`, `stretch/aspect="keep"`, `stretch/scale_mode="integer"`
  - `rendering/textures/canvas_textures/default_texture_filter=0` (Nearest)
  - `rendering/2d/snap/snap_2d_transforms_to_pixel=true`
  - `physics/common/physics_ticks_per_second=60`
  - Renderer stays Forward+. Don't remove the existing Jolt/D3D12 keys.
- [ ] Input actions, each with **≥1 keyboard/mouse event and ≥1 joypad event**: `move_up`, `move_down`, `move_left`, `move_right`, `interact`, `watch`, `ability_next`, `ability_prev`, `confirm`, `cancel`, `journal`, `pause`. Bindings follow GDD §7.
- [ ] `run/main_scene` = `res://scenes/boot/Boot.tscn` (a Control with a centered label "THE LAST FRAME — boot"; no gameplay).
- [ ] `tests/run_tests.gd` (`extends SceneTree`) per ADR-012:
  - recursively discovers `res://tests/**/test_*.gd`
  - instantiates each file and calls every `test_*` method
  - an assertion helper records failures with file, method and message
  - prints a summary line `TESTS: <passed> passed, <failed> failed`
  - `quit(failed)`
- [ ] `tests/test_project_settings.gd` covers:
  - every action above exists with ≥1 key-type and ≥1 joypad-type event
  - viewport is 640×360 with integer scale mode
  - the main scene path exists and instantiates
- [ ] `tools/validate.ps1`: runs the import check, then the tests, and exits non-zero if either fails.

## Acceptance criteria
- [ ] `& $env:GODOT --headless --path . --import` exits 0, with no `ERROR` lines in the output.
- [ ] `& $env:GODOT --headless --path . -s res://tests/run_tests.gd` exits 0 and prints `TESTS: N passed, 0 failed` (N ≥ 3).
- [ ] A deliberately broken assertion (local only, not committed) makes the runner exit non-zero. Show the output in the report.
- [ ] `tools/validate.ps1` returns 0 on the clean tree.
- [ ] Running the project shows Boot at 1920×1080 with crisp, unblurred text (attach a screenshot).
- [ ] `git diff --stat main...` touches only allowed files.
