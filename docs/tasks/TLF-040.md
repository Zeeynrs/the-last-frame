## Why
- **ISSUE-004:** only the title screen (TLF-037) uses `assets/ui/fonts/tlf_pixel_mono.ttf`. HUD, dialogue box, document viewer, journal, interaction prompts and the chapter-complete overlay use Godot's anti-aliased default font, which looks blurry at ×3. Font sizes today are 10, 11, 12, 13, 16 and 32, so they aren't integer multiples of the 8 px font. Even the pixel font renders unevenly at those sizes.
- **ISSUE-033:** `InputPrompts.get_action_glyph` (`scripts/ui/input_prompts.gd:40ff.`) overwrites `key_glyph` on every event, so the **last** binding wins. `confirm` = [LMB, Enter, Space], so it shows "[Space]". Expected: "[Enter]".

## Binding rules (ART_BIBLE §8)
- Font TLF Pixel Mono, native 5×7 glyph in a 6×8 cell. **Allowed sizes only: 8 px (body, prompts, dialogue, journal body), 16 px (headings, room/journal headers), 24 px (chapter title cards).**
- Import: `antialiasing=0`, `hinting=0`, `subpixel_positioning=0` (already set in `tlf_pixel_mono.ttf.import`; don't change it).
- Panels on a 4 px grid, 12 px safe margin, 1 px border `#464E5C` / active `#4CE0D2` / warning `#EB8A28`, fill `#0A0D14` opaque, 4 px text padding.
- Accessibility: `Settings.text_scale` is a float (0.75–2.0). Integer rule: **multiplier 2 when `text_scale >= 1.5`, otherwise 1** (8→16, 16→32, 24→48). Don't change `settings.gd`; apply the mapping in the theme code and **react live** to `Settings.setting_changed(&"text_scale")`.
- Font coverage: ASCII 32–126 only. All player-facing text is already ASCII (ADR-013 am.); the test below guards it.

## Requirements
1. **A single project-wide theme** `scenes/ui/theme/tlf_ui_theme.tres`: `default_font` = TLF Pixel Mono, `default_font_size` = 8, plus styles for Panel/PanelContainer/Button/Label/RichTextLabel/TabContainer following the rules above. Register it in `project.godot` as `gui/theme/custom` (you're the owner of `project.godot`; change this one key only).
2. **Normalise every font size** to 8/16/24: remove or replace all `theme_override_font_sizes/*` in `scenes/ui/*.tscn`, prompt labels in `scenes/chapters/ch01/rooms/*.tscn` (they have no overrides today and pick up the theme; just check that they do), and code-built labels (chapter-complete overlay in `chapter01.gd`, SceneRouter return hint via the theme, journal/document labels built in code). Re-lay out panels so text isn't clipped at 8 px and 16 px (text_scale ×2).
3. **Title screen:** `title_screen.gd` (Opus, TLF-037) builds its own theme at runtime (`FONT_PATH`, `ui_theme.default_font`). Replace that with the project theme, or leave it if it's identical; list it under deltas. Don't change the title's behaviour (navigation, Continue, overwrite confirm); Opus's `tests/ui/test_title_screen.gd` must stay green unchanged.
4. **ISSUE-033 glyph:** primary binding = the **first** `InputEventKey` of the action (respecting the custom bindings from Settings remapping). Fall back to the mouse only if there's no key. For joypads, the first joypad event. `confirm` → "[Enter]", `interact` → "[E]". Remove the hard-coded `"[Enter] Continue"` default text in `DialogueBox.tscn`, or set it at runtime only.
5. Text must not run outside a panel (dialogue box, document viewer, journal, HUD feedback, chapter-complete). If a Ch1 text is too long for the dialogue box at 8 px or 16 px: report it, don't edit `ch01_text.csv`.
