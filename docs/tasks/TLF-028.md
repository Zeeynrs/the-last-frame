# Task: TLF-028 — Make `tools/validate.ps1` robust on Windows PowerShell 5.1

**Owner:** Opus implementation agent (`wt-opus-core`, branch `agent/opus-core`). `tools/` is Flash-written/Opus-approved (ADR-001); Flash is busy with TLF-009, so this goes to Opus.
**Status:** READY · **Priority:** P1 (affects every fresh clone and CI) · **Dependencies:** none

## Problem (reproduced by the Lead, 2026-10-31)
`validate.ps1` sets `$ErrorActionPreference = "Stop"` and captures Godot with `& $Godot ... 2>&1`. On Windows PowerShell 5.1, **every line Godot writes to stderr becomes a terminating `NativeCommandError`**, so the script aborts mid-import (`RemoteException` at the import line) even though Godot itself would finish with exit 0. On a fresh clone this left the CSV translations un-generated, so every following run failed too. Running `godot --import` directly on the same tree exits 0 and generates everything.

## Objective
`validate.ps1` decides pass/fail only from **Godot's exit codes plus `ERROR:` lines in the captured output**, never from PowerShell's stderr handling. It behaves identically on PowerShell 5.1 and 7.

## Allowed files
- `tools/validate.ps1`

## Requirements
- Run Godot without PowerShell turning stderr into exceptions: e.g. `$ErrorActionPreference = "Continue"` around native calls, or `cmd /c "..." 2>&1`, or `Start-Process` with redirected output files. Keep the full log visible.
- Import step: fail on a non-zero exit code or on `ERROR:` lines. Test step: fail on a non-zero exit code (the runner's failure count).
- Keep the `GODOT` env / `-Godot` parameter contract and the clear "not specified / not found" errors.

## Acceptance criteria
- [ ] On a fresh `git archive` of `main` (no `.godot/`), `validate.ps1` exits 0 on the first run.
- [ ] A deliberately broken test makes it exit non-zero; a deliberate GDScript parse error in a scanned script makes the import step fail.
- [ ] Same results under `powershell.exe` (5.1) and `pwsh` (7), if available.
- [ ] Paste the three runs' output in the handoff.

## Stop conditions
Stop and report if detecting failures reliably would need changes outside `tools/validate.ps1`.
