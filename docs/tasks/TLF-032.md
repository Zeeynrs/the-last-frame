## Scope
1. **DialogueBox** (CanvasLayer, bottom of the 640×360 view):
   - plays a sequence of `[speaker_key, text_key]` lines, speaker label from `SPK_*`
   - advance with `confirm`/`interact`, optional auto-advance
   - non-blocking for device lines (the player can keep moving); blocking for Beat 01/09/10 monologue moments
   - one-shot sequences record a flag `heard.<sequence_id>` in NarrativeState, so a sequence never replays after a load
2. **DialogueTrigger** (scene-side, `scripts/ui/` or `scripts/chapters/ch01/`): exported sequence id + lines, fired by `use` (call box, payphone, intercom) or by a zone or signal.
3. **Document viewer**: modal panel on `ReadableDocument.opened`. Title, paging, close with `cancel`. While open, player input is ignored and `SimClock` is paused (`is_paused`) so echoes and timers don't run behind the panel.
4. **Journal screen** (`journal` action): entries grouped by category; collected fragments with title and body; pauses like the document viewer.
5. **Hint**: new input action `hint` (keyboard H + a free joypad button, device −1; must pass the binding-conflict tests). It shows the hint text in the HUD; reasons `no_active_puzzle`/`already_solved` show a short feedback line.
