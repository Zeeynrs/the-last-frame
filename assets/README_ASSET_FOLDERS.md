# Asset Folder Conventions

Suggested folders once the Godot project is created:

- `assets/source/` — editable `.pxo` (Pixelorama) files; the active asset specialist only (Argon; Sol while Argon is unavailable).
- `assets/characters/` — runtime character exports.
- `assets/environments/` — room backgrounds, tiles and set pieces.
- `assets/props/` — interactive and decorative objects.
- `assets/animations/` — runtime spritesheets and animation metadata.
- `assets/vfx/` — temporal, spatial, weather and ambient effects.
- `assets/ui/` — icons, frames, portraits and HUD elements.
- `assets/audio/` — licensed music, ambience and SFX.

Keep source and runtime exports separate. Update `docs/ASSET_INVENTORY.md` for every approved deliverable.
